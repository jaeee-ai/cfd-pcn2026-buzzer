Finalists

Enter the finalists' seat tags. Each finalist scans a QR code and taps their own tag on their phone. As a backup, the operator can buzz a player in by pressing their number (1–5) on this laptop.

Questions

Set up a Google Sheet with three columns: Type, Question, Answer. Type is Warm-up, Main or Sudden win; questions of each type are used in row order. A question can run over several lines (press Ctrl+Enter or ⌘+Enter inside a cell), which suits multiple choice. The answer is optional and only shows on screen after the question is resolved.
