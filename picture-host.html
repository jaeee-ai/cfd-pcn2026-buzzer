Set up the answer options, the answer key and the table PINs. Everything here is saved on this laptop. The answer key never leaves this laptop: phones only receive the options.

Pictures, questions and answer options

Choose the image for each picture: it shows on the live board and on guests' phones. Leave option D blank if a picture only has three choices. Pick the correct letter on the right.

Table PINs

Each table needs its PIN to submit. Print the cards and put one on each table. Tick Staff table for tables that play for fun: they can submit, but they're left out of the race positions, the leaderboard and the prizes.
